Introduction to Mathematical Induction

Mathematical Induction is a special method of proof. We use it when we want to show that a statement is true for every natural number. Natural numbers are 1, 2, 3, 4, 5, … and so on. We write this set as N.

In algebra we often meet formulas such as

1 + 2 + 3 + … + n  =  n(n + 1) / 2

and

1² + 2² + 3² + … + n²  =  n(n + 1)(2n + 1) / 6

How can we be sure that such a formula works for every n? We cannot check infinitely many numbers one by one. Mathematical Induction gives us a short and logical way to prove the result for all n at once.

What does the word “induction” mean?

Induction means moving from a particular case to a general result. First we check the statement for a small value, usually n = 1. Next we show that if the statement is true for one number, it must be true for the next number. In this way the result climbs up to all natural numbers.

The domino picture

Think of a long row of standing dominos.

  1. If we push the first domino, it falls.
  2. If any one domino falls, it knocks down the next one.

Then every domino in the row will fall. Mathematical Induction works in exactly this way. The first falling domino is the base case. The knocking of the next domino is the inductive step.

Why is this topic important?

  • It is a standard method in NCERT Class 11 Mathematics.
  • It is used to prove formulas of sequences and series.
  • It is used to prove divisibility results in number theory.
  • It is used in inequalities, algebra and even in computer science (loops and recursion).
  • It trains us to write clear, step-by-step logical proofs.

In this project we shall study the principle, write it in mathematical form, solve five examples, and discuss its uses, merits and limitations.

Principle of Mathematical Induction (PMI)

The Principle of Mathematical Induction is a basic rule of natural numbers. It tells us when a statement about n is true for every natural number n.

Let P(n) stand for a statement that involves a natural number n. For example,

P(n) :   1 + 2 + 3 + … + n  =  n(n + 1) / 2

For each value of n, P(n) is either true or false. Our aim is to prove that P(n) is true for all n in N.

The principle (in simple words)

If

(i) P(1) is true, and

(ii) whenever P(k) is true, then P(k + 1) is also true,

then P(n) is true for all natural numbers n.

This is called the First Principle of Mathematical Induction. NCERT treats it as an axiom of the natural numbers. We accept it and use it to prove other results.

The basic idea

We do not prove the result for every n separately. We only do two things:

Step A. Start the chain — check the statement for n = 1.

Step B. Keep the chain going — show that truth at k forces truth at k + 1.

Once both are done, the chain never breaks. So the statement is true for n = 1, then 2, then 3, then 4, and so on, without end.

Why does the chain work?

P(1) is true by Step A. Using Step B with k = 1, we get P(2). Using Step B with k = 2, we get P(3). Continuing like this, we reach P(n) for every natural number n.

P(1) → P(2) → P(3) → P(4) → … → P(n) → …

Points to remember

  • The starting value need not always be 1. If a statement is given for n ≥ 0 or n ≥ 2, we take that smallest value as the base case.
  • P(n) must be a clear mathematical sentence, not a vague sentence.
  • Induction is a method of proof. It does not invent the formula. First we are given (or we guess) a formula. Then we prove it.
  • Both parts of the principle are needed. A true base case with a false inductive step, or a true inductive step with a false base case, is not a valid proof.

In the next page we study these two steps in detail: the base case, the inductive hypothesis and the inductive step.

The Two Main Steps of Mathematical Induction

To prove a statement P(n) by mathematical induction we always follow two main steps. Both steps are necessary. If even one of them is missing, the proof is incomplete.

Step 1 — Base Case (Basic Step)

In this step we put the smallest allowed value of n into P(n) and check that the statement is actually true. In most school problems this value is n = 1.

We write:   P(1) is true.

Example. Let P(n) be

1 + 3 + 5 + … + (2n − 1)  =  n²

Then P(1) means 1 = 1², which is true. The base case is verified.

This step is like pushing the first domino. If the first statement is false, the whole proof fails, even if the second step looks correct.

Note: Always show the actual calculation for n = 1 (or the given starting value). Do not just write “it is obviously true”.

Step 2 — Inductive Hypothesis and Inductive Step

(a) Inductive Hypothesis (I.H.)

We assume that the statement is true for some natural number k. That is, we assume P(k) is true. This assumption is called the inductive hypothesis.

We are not saying that P(k) is true for every k. We only assume it for one fixed k, so that we can study the next number k + 1.

(b) Inductive Step

Using the inductive hypothesis, we prove that P(k + 1) is true. In symbols we show

P(k) is true   ⇒   P(k + 1) is true

This is like proving that if one domino falls, the next one also falls. In the working we must use P(k) in a clear way. Writing “similarly it is true for n = k + 1” without algebra is not a proof.

How the two steps sit together

StepNameWhat we doDomino picture
1Base caseProve P(1)Push the first domino
2(a)I.H.Assume P(k)Suppose the k-th domino falls
2(b)Inductive stepProve P(k + 1)Then the (k + 1)-th also falls

Conclusion of a proof

If both steps succeed, we write:

Hence, by the Principle of Mathematical Induction, P(n) is true for all n ∈ N.

Common mistakes: skipping the base case; assuming P(k + 1) instead of proving it; and using P(n) for all n inside the inductive step (that would be circular).

Mathematical Formulation of PMI

Let P(n) be a statement associated with a positive integer n. The Principle of Mathematical Induction can be written in compact form as follows.

Statement of PMI

If  (i) P(1) is true, and

(ii) P(k) true  ⇒  P(k + 1) true, for any k ∈ N,

then P(n) is true for all n ∈ N.

Meaning of P(n), P(k) and P(k + 1)

These three are not three different formulas. They are the same statement written for different values of the variable.

1. P(n) — the general statement

P(n) is the result we want to prove. The letter n is a variable standing for a natural number.

Example:   P(n) :   2n > n

Here P(n) talks about every n. Our job is to prove it.

2. P(k) — the inductive hypothesis

P(k) is the same statement with n replaced by k. Here k is a particular natural number. When we assume P(k) is true, we are making the inductive hypothesis.

Example:   P(k) :   2k > k

3. P(k + 1) — the next case

P(k + 1) is the statement for the next natural number after k. In the inductive step we must prove this, using P(k).

Example:   P(k + 1) :   2k+1 > k + 1

Order of writing a school proof

  1. Write P(n) clearly in words or in symbols.
  2. Prove P(1).   [Base case]
  3. Assume P(k) is true.   [Inductive hypothesis]
  4. Prove P(k + 1), showing every algebraic step and using (3).
  5. Conclude that P(n) is true for all n ∈ N, by PMI.

Set language (optional extra)

Let S = { n ∈ N : P(n) is true }. If 1 ∈ S and (k ∈ S ⇒ k + 1 ∈ S), then S = N. This is the same principle written with sets.

Highlight: Replace n by 1 to get P(1). Replace n by k to get P(k). Replace n by k + 1 to get P(k + 1). Always write P(k + 1) by putting n = k + 1 in the original statement, not by guesswork.

We now apply this formulation to five standard examples from sequences, inequalities and divisibility.

Solved Example 1 — Sum of First n Natural Numbers

To prove: For every natural number n,

1 + 2 + 3 + … + n  =  n(n + 1) / 2

Let P(n) be the statement

P(n) :   1 + 2 + 3 + … + n  =  n(n + 1) / 2

Step 1. Base case (n = 1)

Left side of P(1) = 1

Right side of P(1) = 1(1 + 1) / 2 = 1 × 2 / 2 = 1

Left side = right side. Therefore P(1) is true.

Step 2. Inductive hypothesis

Assume that P(k) is true for some natural number k. That is,

1 + 2 + 3 + … + k  =  k(k + 1) / 2    ...(1)

This is the inductive hypothesis.

Step 3. Inductive step (prove P(k + 1))

We must prove

P(k + 1) :   1 + 2 + … + k + (k + 1)  =  (k + 1)(k + 2) / 2

Start from the left side of P(k + 1):

L.H.S. = 1 + 2 + … + k + (k + 1)

       = [1 + 2 + … + k] + (k + 1)

       = k(k + 1) / 2  +  (k + 1)    [using (1)]

       = (k + 1) [ k/2 + 1 ]

       = (k + 1) [ (k + 2) / 2 ]

       = (k + 1)(k + 2) / 2

       = R.H.S. of P(k + 1)

So P(k + 1) is true whenever P(k) is true.

Conclusion

P(1) is true, and P(k) ⇒ P(k + 1). Therefore, by the Principle of Mathematical Induction, P(n) is true for all natural numbers n.

Important formula: Sum of first n natural numbers = n(n + 1)/2. This is also the n-th triangular number. Check: for n = 5, 1+2+3+4+5 = 15 and 5×6/2 = 15.

Solved Example 2 — Sum of First n Odd Numbers

To prove: For every natural number n,

1 + 3 + 5 + … + (2n − 1)  =  n²

The n-th odd natural number is 2n − 1. So the left side is the sum of the first n odd numbers. Let

P(n) :   1 + 3 + 5 + … + (2n − 1)  =  n²

Step 1. Base case (n = 1)

Left side of P(1) = 1   (only the first odd number)

Right side of P(1) = 1² = 1

Hence P(1) is true.

Step 2. Inductive hypothesis

Assume P(k) is true for some k ∈ N:

1 + 3 + 5 + … + (2k − 1)  =  k²    ...(1)

Step 3. Inductive step (prove P(k + 1))

The next odd number after (2k − 1) is (2k + 1), because

2(k + 1) − 1 = 2k + 2 − 1 = 2k + 1

We must prove

P(k + 1) :   1 + 3 + … + (2k − 1) + (2k + 1)  =  (k + 1)²

L.H.S. = [1 + 3 + … + (2k − 1)] + (2k + 1)

       = k² + (2k + 1)    [using (1)]

       = k² + 2k + 1

       = (k + 1)²

       = R.H.S.

Thus P(k + 1) is true whenever P(k) is true.

Conclusion

By PMI, P(n) is true for all n ∈ N. That is, the sum of the first n odd natural numbers is n².

A small check and a picture

For n = 4: 1 + 3 + 5 + 7 = 16 = 4². We can also see this as a square of dots. Each new odd number adds a new L-shaped border (called a gnomon) and the figure remains a square.

Important formula: 1 + 3 + 5 + … + (2n − 1) = n².

Solved Example 3 — An Inequality: 2n > n

To prove: 2n > n   for all positive integers n.

This example shows that induction is not only for equalities. It also works for inequalities. Let

P(n) :   2n > n

Step 1. Base case (n = 1)

21 = 2   and   n = 1.   Now 2 > 1, which is true.

Hence P(1) is true.

(We may also glance at n = 2: 22 = 4 > 2, true. This extra check is not required, but it builds confidence.)

Step 2. Inductive hypothesis

Assume P(k) is true for some k ∈ N:

2k > k    ...(1)

Step 3. Inductive step (prove P(k + 1))

We must prove 2k+1 > k + 1.

L.H.S. = 2k+1 = 2 · 2k

       > 2 · k    [by (1), because 2k > k]

       = 2k

We now need 2k compared with k + 1. For every natural number k,

2k − (k + 1) = k − 1 ≥ 0   for k ≥ 1

so 2k ≥ k + 1. Equality holds only when k = 1 (then 2k = 2 = k + 1). For k ≥ 2 we have 2k > k + 1.

Therefore

2k+1 > 2k ≥ k + 1

When k = 1, the first inequality is strict (because 2k > k), so

2k+1 > 2k = k + 1   ⇒   2k+1 > k + 1

When k ≥ 2, 2k+1 > 2k > k + 1, so again 2k+1 > k + 1.

In both cases P(k + 1) is true.

Conclusion

By PMI, 2n > n for all positive integers n.

Remark: Exponential growth (powers of 2) overtakes linear growth (the number n itself). A few values: n = 1 → 2 > 1; n = 5 → 32 > 5; n = 10 → 1024 > 10.

Solved Example 4 — A Divisibility Result

To prove: 7n − 1 is divisible by 6 for all positive integers n.

In other words, 6 divides (7n − 1), or we can write

7n − 1 = 6m   for some integer m

Let P(n) be the statement

P(n) :   7n − 1 is divisible by 6

Step 1. Base case (n = 1)

71 − 1 = 7 − 1 = 6

and 6 = 6 × 1, which is clearly divisible by 6.

Hence P(1) is true.

Step 2. Inductive hypothesis

Assume P(k) is true. Then 7k − 1 is divisible by 6, so there exists an integer m such that

7k − 1 = 6m    ⇒   7k = 6m + 1    ...(1)

Step 3. Inductive step (prove P(k + 1))

We must show that 7k+1 − 1 is divisible by 6.

7k+1 − 1 = 7 · 7k − 1

             = 7(6m + 1) − 1    [using (1)]

             = 42m + 7 − 1

             = 42m + 6

             = 6(7m + 1)

Now (7m + 1) is an integer. Therefore 7k+1 − 1 is a multiple of 6.

Hence P(k + 1) is true whenever P(k) is true.

Conclusion

By the Principle of Mathematical Induction, 7n − 1 is divisible by 6 for all positive integers n.

Solved Example 5 — Sum of Squares

To prove: For every natural number n,

1² + 2² + 3² + … + n²  =  n(n + 1)(2n + 1) / 6

Let P(n) denote this statement.

Step 1. Base case (n = 1)

L.H.S. of P(1) = 1² = 1

R.H.S. of P(1) = 1(1 + 1)(2 + 1) / 6 = 1 × 2 × 3 / 6 = 6 / 6 = 1

Hence P(1) is true.

Step 2. Inductive hypothesis

Assume P(k) is true:

1² + 2² + … + k²  =  k(k + 1)(2k + 1) / 6    ...(1)

Step 3. Inductive step (prove P(k + 1))

We must prove

1² + … + k² + (k + 1)²  =  (k + 1)(k + 2)[2(k + 1) + 1] / 6

that is, R.H.S. = (k + 1)(k + 2)(2k + 3) / 6.

L.H.S. = k(k + 1)(2k + 1)/6  +  (k + 1)²   [by (1)]

       = (k + 1) [ k(2k + 1)/6  +  (k + 1) ]

       = (k + 1) [ k(2k + 1) + 6(k + 1) ] / 6

       = (k + 1) [ 2k² + k + 6k + 6 ] / 6

       = (k + 1) (2k² + 7k + 6) / 6

Factorise the quadratic: we look for two numbers whose product is 2 × 6 = 12 and whose sum is 7. These are 3 and 4.

2k² + 7k + 6 = 2k² + 3k + 4k + 6 = k(2k + 3) + 2(2k + 3)

                 = (2k + 3)(k + 2)

Check: (2k + 3)(k + 2) = 2k² + 4k + 3k + 6 = 2k² + 7k + 6. Correct.

L.H.S. = (k + 1)(k + 2)(2k + 3) / 6 = R.H.S.

Hence P(k + 1) is true.

Conclusion

By PMI, the formula holds for all n ∈ N.

Important formulas:

∑ n = n(n+1)/2,   ∑ n² = n(n+1)(2n+1)/6,   ∑ n³ = [n(n+1)/2]²

Check: n = 3 → 1+4+9 = 14, and 3×4×7/6 = 84/6 = 14.

Applications of Mathematical Induction

Mathematical Induction is not a topic that lives only in one chapter. Once we learn it, we meet it again and again in algebra, sequences, number theory and even in computer science. Some important applications are given below.

1. Sequences and series

Many standard sums are proved by induction. We have already proved three of them:

  • sum of first n natural numbers
  • sum of first n odd numbers
  • sum of squares of first n natural numbers

In the same way we can prove

1³ + 2³ + … + n³  =  [n(n + 1)/2]²

and the formula for the sum of a geometric series

1 + r + r² + … + rn−1 = (rn − 1)/(r − 1),   r ≠ 1

Arithmetic and geometric progressions in Class 11 become more rigorous when their formulas are proved by PMI.

2. Algebra and inequalities

Induction is used to prove results such as:

  • 2n > n   (Example 3 of this project)
  • n < 2n and n! > 2n for sufficiently large n
  • Bernoulli-type inequalities, for example (1 + x)n ≥ 1 + nx for x ≥ −1, n ∈ N
  • identities like (a + b)n expansions in special cases, and De Moivre’s theorem in complex numbers (Class 11)

3. Divisibility and number theory

A large family of Class 11 / 12 problems is of the type “show that an expression is divisible by a fixed integer”. Example 4 was one such result. Other typical statements are:

  • 3n − 1 is divisible by 2
  • xn − yn is divisible by x − y
  • n³ + 2n is divisible by 3
  • 10n − 1 is divisible by 9 (a string of n nines)

The method is always the same: write the k-case as a multiple of the given number, then factor the (k + 1)-case.

4. Other branches

Binomial theorem: the identity C(n, r) + C(n, r − 1) = C(n + 1, r) can be used with induction on n to prove (x + y)n = ∑ C(n, r) xn−r yr.

Computer science: correctness of loops, recursion (factorial, Fibonacci) and the complexity of divide-and-conquer algorithms (such as binary search) are often proved by induction on the size of the input.

Sets and logic: many results about finite sets (for example, a set with n elements has 2n subsets) are proved by induction on n.

Thus PMI is a bridge between Class 11 algebra and later work in higher mathematics.

Advantages, Limitations and Importance

Advantages

  • It proves a result for infinitely many numbers in a finite number of steps.
  • The method is uniform. Once we learn the two-step pattern, we can apply it to sums, inequalities and divisibility.
  • It makes our reasoning exact. Every step is written, so mistakes are easy to find.
  • It matches the way natural numbers are built: start at 1 and keep adding 1.
  • It is accepted in board examinations as a complete method of proof.

Limitations

  • We must already know (or guess) the statement P(n). Induction does not discover the formula; it only proves it.
  • It works directly for statements about natural numbers (or integers from some starting point). It is not the right tool for statements about all real numbers.
  • If the inductive step is written carelessly, we may think we have a proof when we do not.
  • Some true statements need a stronger form (strong induction), where we assume P(1), P(2), …, P(k) to prove P(k + 1). Fibonacci identities often need this.
  • A wrong base case cannot be saved by a correct inductive step.

Importance for a Class 12 student

Even though the main NCERT chapter on PMI is in Class 11, the method is used in Class 12 whenever we justify a general term, a sum, or a divisibility fact. It also prepares us for proofs in college mathematics. Learning to write P(n), P(k) and P(k + 1) clearly is itself a useful examination skill.

Flowchart of the two-step process

Start: write the statement P(n)
↓
Step 1 — Base case: prove P(1) [or the first allowed n]
↓
If P(1) is false, stop. Proof fails.
If P(1) is true, go on
↓
Step 2(a) — Assume P(k) is true (Inductive Hypothesis)
↓
Step 2(b) — Using P(k), prove P(k + 1)
↓
By PMI, P(n) is true for all n ∈ N. End.

Conclusion

Mathematical Induction is a simple but powerful method of proof. It rests on two ideas only: check the first case, and show that each case leads to the next. With these two steps we can prove statements for every natural number.

In this project we began with the meaning and importance of induction, using the familiar picture of falling dominos. We then wrote the Principle of Mathematical Induction in words and in symbols, and we explained P(n), P(k) and P(k + 1) carefully.

Five solved examples were presented:

  1. 1 + 2 + … + n = n(n + 1)/2
  2. 1 + 3 + … + (2n − 1) = n²
  3. 2n > n for all positive integers n
  4. 7n − 1 is divisible by 6
  5. 1² + 2² + … + n² = n(n + 1)(2n + 1)/6

These examples cover the three main types of school problems: summation formulas, inequalities and divisibility. We also noted applications in sequences, algebra, the binomial theorem and computer science, and we listed the advantages and limitations of the method. The flowchart on the previous page is a short revision of the whole process.

A student who can write a clean induction proof has learnt more than one chapter. The student has learnt to start from a definition, to use an assumption honestly, and to finish with a clear conclusion. That habit of mind is the real value of this project.

I conclude that the Principle of Mathematical Induction is an essential tool in Class 11 and Class 12 Mathematics, and that regular practice of such proofs builds accuracy and confidence.
